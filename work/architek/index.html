Designing a route from an architectural brief to a reviewable output.

A convincing building image is not the same as a file an architect can revise or hand to an engineer. The interface needs to make the intended output and its limits clear.

Product designer · 2025

I designed prompt entry, design-type selection, generated alternatives, preview and export flows, plus the proposed 3D-editor experience.

The decisions behind the interface

  • Help people start with a recognisable building brief. Examples such as a three-bedroom bungalow or duplex sit beside the prompt field, with sample designs to show what can be requested.
  • Let the user choose the output level. Concept Sketch, Schematic Plan and Detailed Model make fidelity an explicit choice rather than leaving the generator to guess.
  • Keep alternatives and export choices visible. Named design options can be compared before choosing DWG, OBJ, SketchUp or PDF. The proposed editor is labelled Coming soon.

What was delivered

The interface design covers the path from a written brief through comparison, preview and proposed export. The mockups show these interaction decisions.

Style guide

[Overview]

Everything Jamiu’s portfolio is made of, on one page: the color variables behind the light and dark themes, the type scale, spacing, links, buttons, form fields and the small components every page is built from. Colors and the typeface are Webflow Variables, so a change in the Variables panel reaches every page at once. Sizes live in the classes, in em.

[Rich text]

Blog posts are written in a Rich Text element with the class text-rich-text. Inside it, each tag has its own style on top of the tag styles above: select a heading, a paragraph or a quote in this sample to edit the look of every post at once.

Start with who edits it next

Before I decide how a page should move, I ask who will change it after launch. A marketing team edits headlines every week, so anything they touch should live in the Designer, not in a script. More on that in the journal.

Keep the system small

One typeface, three weights and a handful of sizes cover a whole portfolio. Every extra style is one more thing a client has to keep consistent.

  • One class per text style, reused everywhere
  • Colors as variables, so dark mode is one switch
  • Sizes in em, so the page scales as a whole
  1. Write the content first
  2. Set the type scale around it
  3. Add motion last, and only where it helps
If a client would ask me to change it, it belongs somewhere they can reach.

[Spacing & scale]

  • Scale

    Scale system

    Every size is in em, measured from page-wrapper: 16px up to 1440px wide, then growing with the screen to 21.33px at 1920px. Tablet and mobile stay at 16px.

  • No scale

    Fixed 16px

    The combo is--no-scale on page-wrapper keeps a page at 16px on every screen. Every Jamiu’s portfolio page uses it; remove it to let a page grow on wide screens.

  • Gutters

    Gutters

    padding-global sets the left and right gutters: 40px on desktop, 24px on tablet and 20px on mobile. Pages are full width, with no container.

  • Breakpoints

    Desktop first

    Styles start on desktop and are adjusted on three smaller breakpoints.

    • Desktop · 992px and up
    • Tablet · 991px
    • Mobile landscape · 767px
    • Mobile portrait · 479px

  • Spacing

    Spacing scale

    Gaps and paddings come from one scale, in the Spacing collection. Components space their children with gap.

    • Space 1 · 4px
    • Space 1 Half · 6px
    • Space 2 · 8px
    • Space 2 Half · 10px
    • Space 3 · 12px
    • Space 4 · 16px
    • Space 5 · 20px
    • Space 6 · 24px
    • Space 7 Half · 30px
    • Space 8 · 32px

  • Radius

    Corners

    Cards, images and form messages use 10px (0.625em). Buttons, chips, pills and dots are fully round (100em). Lines are 1px hairlines, dashed between rows.

[Utilities]

  • Layout

    Text measure

    max-width-medium caps a block of text at 36em (576px), the width of the Home bio.

  • Layout

    Containers

    container-small, container-medium and container-large center content at 960, 1200 and 1360px. The pages are full width; use them in sections you add.

  • Access

    Screen readers

    sr-only hides text on screen but keeps it for screen readers, like the “opens in a new tab” note on outside links.

  • Access

    Skip link

    skip-link is the first thing a keyboard reaches. It appears on focus and jumps to the main content.

  • Type

    Label

    text-style-label is the small uppercase style for row labels, captions and the copyright line.

  • Combo

    Variants

    is--last removes the hairline under the last list row. is--stretch lets a row’s content fill its column. is--no-scale fixes a page at 16px. is--grid crops card media to 16:10. is--active marks the current theme label.

  • Naming

    Client-First

    Parts of a block use an underscore (page-row_content), shared styles a hyphen (text-style-label), variants start with is--. Reuse a class before creating a new one.

[Interactions & code]

  • Interaction

    Scroll reveal

    Each row below the first fades up as it scrolls into view. It is a native interaction: select the row and open the Interactions panel to change or remove it.

  • Interaction

    Hovers

    The button fill and the work card pill are native hover interactions on button and work-card_link, editable in the same panel.

  • Script

    Site script

    Smooth scroll, the Welcome screen, the theme switch, the clock and the underline links run from one script in Site settings → Custom code → Footer.

    What each feature does

  • Head code

    Font smoothing

    The only custom style in the site head is font smoothing on page-wrapper. Everything else is a class you can edit in the Style panel.

[Script states]

These classes are added while the page runs, by the site script or by the blog pagination, so they are on no element in the Designer and Webflow’s Clean Up lists them as unused. Don’t delete them: a hidden block at the end of this page carries each one, which keeps them in use and editable.

  • Body

    Dark mode

    theme-dark goes on the body when a visitor picks Dark and turns on the Dark mode of the Colors collection.

  • Welcome

    Welcome screen

  • Cursor

    Custom cursor

    cursor-bracket styles the two brackets that follow the pointer on desktop.

  • Home

  • Blog post

    Contents
